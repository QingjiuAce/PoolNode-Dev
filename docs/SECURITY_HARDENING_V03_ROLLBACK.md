# V0.3 迁移和回滚

保持 `guard_system_disk: true`。安全模式要求公开根、真实目标父目录和暂存同设备；路径应为真实目录而不是软链接或 Windows 目录重解析点。审计文件必须在非系统设备上、为普通单链接文件；不会创建未使用的 `log_dir` 或暂存目录。显式 `false` 只用于知情的单盘开发或兼容环境。

上线前由运维核对实际配置和挂载身份，在隔离 Debian 12 环境完成[演练](<DEBIAN12_MOUNT_GUARD_TEST_REPORT.md>)，另行批准部署。本次不执行生产操作。用 root 所有、业务用户不可写的底层挂载点作为第二道防线；不能对已挂载的生产路径直接变更权限。

若需回退：先停用同步及删除作业，保留已发布文件、审计与配置备份；确认数据盘可用后，人工回退应用代码到经批准版本。保留 `guard_system_disk: true`，不要用关闭保护消除故障。基线 `7ac2621` 保留默认保护，但没有 V0.3 的描述符保证。若出现替换/删除已执行但审计或核验失败，先人工核对资产与 JSONL；不要盲目重试。
