## 刻意不改

授权数据、配置示例、部署脚本、依赖、生产实测和既有性能文档均不改。下载器诊断的取样特征不是发布格式验证；白名单 URL 校验不是传输层的重定向策略。这些表面相似的逻辑不合并。

遗留问题另立变更：发布与审计不是一个事务，部分未分类的文件系统错误仍可能直接抛出，既有本地诊断文字包含路径。跨文件系统失败时的暂存收尾、对目录配置与删除路径的防御深度、测速脚本既有的报告组装问题和部署回滚行为，都不在本次修改范围。没有用注释把它们标为已修复。
