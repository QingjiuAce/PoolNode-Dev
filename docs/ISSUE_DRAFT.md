## 正文

### 背景：raw 的可达性问题

详情页"下载原图"走 `raw.githubusercontent.com`。实测它在大陆**不是"慢"，是分网络链路层不可达**：

| 网络 | 结果 |
|---|---|
| 中国移动 5G | 100% 可达（CMI 出口放行），中位延迟 433ms |
| 中国广电 5G | DNS 投毒 0.0.0.0，20/20 全失败 |
| 家宽直连 | DoH 拿真 IP 后直连，4/4 RST——IP 层封，换 DNS 无效 |

GreatFire 监测：90 天内 100% 出现干扰（2026-11-19 数据）。

影响：创作者拿不到原图 → 无法二创 → 无法回流投稿。下载这步断的是内容增长的输入端。

### 已做的 PoC（不是提案空谈，是可以点开的）

在香港搭了一个独立只读节点，**路径与 ai-girl-stickers 仓一比一对应**（不替换 Raw、不改已发布 URL，符合 AGENTS.md 的路径约束）：

- 入口：https://dl.bszx.site（临时域名，正式域名/子域听站长的）
- 现有内容：40 张自生成测试图（1–4 MB 梯度），全部经完整 sync 管线发布，SHA256 对照表见 reports/demo/
- 晚高峰实测（移动宽带 · 22:48–23:25）：单流 0.4 Mbps，**16 段并发 4.5 Mbps，64 流聚合 22 Mbps**——整形是 per-flow，无总量拐点，客户端分段并发可绕
- 完整数据：IMAGE_DOWNLOAD_REPORT.md（附件），含三网样本、DoH 实验、剂量-响应曲线，方法可复现
