# 大陆网络测试指引

> 目的：验证大陆各运营商访问 Pool 节点的真实体验。
> **必须区分两个方向**：香港→GitHub Raw（回源）与 大陆→香港 Pool（用户体验），
> 不能互相替代。本指引只覆盖后者；前者见 docs/TEST_REPORT.md 的上游测试章节。

## 1. 测试脚本

在**大陆的电脑**上（Windows 用 Git Bash / WSL；Linux/macOS 原生）运行：

```bash
bash china-speedtest.sh https://<POOL_DOMAIN>/pool-tests/test-poc-001.png 3
```

脚本自动采集并保存到 `pool-speedtest-<时间>.txt`：

- ping 丢包率与延迟（10 包）
- DNS 解析结果
- 三次独立下载：DNS / TCP / TLS 握手 / TTFB / 总耗时 / 平均速度 / HTTP 状态码 / SHA256

## 2. 测试矩阵

| 运营商 | 时段 | 备注 |
| --- | --- | --- |
| 中国移动 | 空闲 + 晚高峰 | 服务器路由经 CMI→NTT，理论最亲和 |
| 中国联通 | 空闲 + 晚高峰 | 回程 163→219.158 |
| 中国电信 | 空闲 + 晚高峰 | 回程 CN2→163 |
| 中国广电 | 条件允许 | 常与移动共用通道，注意区分 |

**晚高峰定义：北京时间 20:00–23:00**。每组测试请记录：

1. 运营商 + 城市 + 接入方式（家宽/4G/5G）
2. 时段
3. 脚本输出文件内容

## 3. 结果解读

- `sha256` 应等于 `python3 -m pool verify test-poc-001` 输出的哈希（字节级一致）；
- `speed` 单位 B/s，×8/1e6 = Mbps；
- 晚高峰 TTFB/speed 明显劣化属正常观察项，请如实记录，不做美化；
- 单次结果不代表稳定性，3 次重复 + 多天观察才可信。

## 4. 诚实声明

- 在没有大陆外部测试机反馈前，**本报告不包含任何大陆测速数字**，
  也不会用香港本地测试冒充大陆体验；
- 服务器官方带宽 300 Mbps 是端口能力，不等于任意用户单线程可达速度。
