## 兼容性证据

- 原有测试重新验证 pending、denied、无证据拒绝，获准后发布，未登记资产拒绝、初始 URL 与重定向限制、官方 SHA256、内容格式、同盘发布替换、删除和篡改检测。
- 新增 9 项：CLI help/解析错误两项、配置/清单错误两项、清单默认位置/环境变量覆盖两项、TLS context 的证书和主机名校验一项、无 Content-Length 的流式超限清理一项、本地哈希发布及用不同但格式合法的 PNG 覆盖后验证失败一项。新增测试不建立真实上游连接。
- GET、HEAD、Range、404、静态资源方法限制、ACME 跳转例外与缓存头，均核对模板中的相关指令未变。CLI 仍只有受登记资产 ID 约束的命令，无任意 URL 参数或公网管理接口。
