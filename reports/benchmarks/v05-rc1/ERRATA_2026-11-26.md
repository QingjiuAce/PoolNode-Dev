# v0.5.0-rc.1 配对实验勘误（2026-11-26）

> 结论：**原 5.4 MiB 的 B vs D 性能对比全部无效**。B 臂从未以 static 执行，
> 实际与 D 臂同为 dynamic。基于该对比的健康窗/劣化窗验收判据**从未被真正测量**。
> 本文件不删除、不改写任何原始记录；`REPORT.md` 原文保留作历史记录。

## 1. 缺陷事实

`scripts/bench_v05_pairs.py` 旧实现：

```python
def run_client(..., scheduler=None):
    ...
    if scheduler:                 # B 臂 scheduler=None -> 不传 --scheduler
        cmd += ['--scheduler', scheduler]
    return {'arm': ('D' if scheduler is not None else 'B'), ...}
```

而 `pool/fetch.py` 的默认值是 `--scheduler auto`，5.4 MiB（bench-6m）按
`auto` 解析为 `dynamic`。因此：

| Arm | 标签声称 | 实际 CLI | 实际执行 | 是否策略对比 |
|---|---|---|---|---|
| B | v0.4 static | 未传 `--scheduler` → `auto` | **dynamic** | 否 |
| D | v0.5 auto/dynamic | `--scheduler auto` | **dynamic** | 否 |

两臂走的是**同一条 dynamic 代码路径**，差异仅为进程启动参数缺省与标签。

## 2. 证据链

1. **代码路径**：如上，B 臂不传 `--scheduler`；客户端默认为 `auto`；阈值在
   `pool/fetch.py:55`（`size >= 4MiB` → dynamic）。
2. **客户端输出**：恢复的 20 份 metrics（健康窗 10 + 劣化窗 10）中，
   `download.scheduler` **全部为 `dynamic`**，包括 `runs.jsonl` 标记为 `arm=B`
   的 5 条。见 `recovered/RECOVERY_MANIFEST.md` §5。
3. **汇总字段不足**：`runs.jsonl` 的 `mode="range"` 只说明用了 Range/206，
   无法区分 static 与 dynamic，因此旧汇总无法自证策略。
4. **分支事实**：`v0.5.0-rc.1` 的 `pool/` 与 alpha 同树；`fetch.py` 默认值未变。

## 3. 撤回的结论

以下表述**不得再被引用为验收证据**：

| 原结论 | 处置 |
|---|---|
| 健康窗退化 ≤10%（最大 −8.3%）→ 通过 | **撤回**：static 臂不存在，判据未测量 |
| 健康窗 P90 退化 ≤15% → 通过 | **撤回**：同上 |
| 5.4 MiB −8.3% 落在“同路径噪声带”内 | **撤回**：该差值是两个 dynamic 运行的噪声 |
| 劣化窗 −18.5% / +4.9% / −13.4% / +0.4%（中位 +0.4%） | **撤回**：dynamic vs dynamic，不构成策略对比 |
| 劣化窗未达 ≥30% 门槛 | **撤回**：门槛针对 auto vs static，未实际执行 |
| 1.7/2.0 MiB “同路径噪声对照” | **保留但降级**：两臂同为 static，作为噪声带有效，**不是**策略对比 |

## 5. 修复与复测状态

- Harness 已修复（本日提交）：B 显式传 `--scheduler static`；D 显式传
  `--scheduler auto`；Arm 身份由 `ARM_SPECS` 预先声明；运行后以客户端
  metrics/JSON 的 `scheduler` 字段做 `policy_ok` 校验；metrics 路径带唯一
  run_id；重叠运行输出 `SKIPPED_OVERLAP`。
- 自动化测试：`tests/test_bench_harness.py`（13 项），包含“B 实际 dynamic
  必须判失败”的回归用例。
- **真实网络复测尚未执行**。复测计划见 `RETEST_PLAN_2026-11-26.md`；
  在完成至少 5 组健康窗 + 5 组劣化窗配对前，V0.5 不具备重新验收条件。
